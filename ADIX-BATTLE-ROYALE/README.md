# ADIX BATTLE ROYALE

A separate Android battle royale game project.

## Project goals
- Offline single-player battle royale
- 50 AI bots
- Third-person and first-person camera modes
- Large island and city map
- Drivable vehicles, including a helicopter
- Android build target

## Development notes
This folder is intentionally separate from the existing AdixLoop app files. The game is not yet a complete playable build or APK; gameplay systems, scenes, assets, device optimization, and Android build configuration still need to be implemented and tested.

## Game size target
- Minimum installed size: **250–300 MB**.
- Premium target: **500 MB to 1 GB**, when supported by genuine high-quality maps, models, textures, animation, effects and offline audio.
- All core game content remains available offline.
- APK download size and installed size will be tracked separately; compression means they will not be identical.
- No artificial padding or duplicated assets just to reach a size number.
